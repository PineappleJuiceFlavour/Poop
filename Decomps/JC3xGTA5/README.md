# JC3xGTA5

Just Cause 3-style gameplay in GTA 5 (story mode), built with the Spreadsheet Method.

`sheets/*.csv` → `codegen/gen.py` → `mod/generated/*.h` → `mod/src/main.cpp` → `JC3xGTA5.asi`

| Action | Control |
|---|---|
| Grapple | Hold aim (RMB/LT) + fire (LMB/RT) |
| Wingsuit | Space/A while airborne |
| Detonate at hook point | G / D-pad left |
| Infinite parachutes | always on |

Setup: install ScriptHookV, put its SDK in `mod/sdk/`, then run `play.bat` from the repo root.
Story mode only. Don't use it online.
